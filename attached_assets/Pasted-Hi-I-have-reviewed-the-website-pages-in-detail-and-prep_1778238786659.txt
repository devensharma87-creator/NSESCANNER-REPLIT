Hi,

I have reviewed the website pages in detail and prepared a full audit document. Please treat this as an **additional improvement and fixing document**, not a complete redesign request.

The current website already has a strong foundation, especially the dark pro-trader UI, market dashboard structure, option chain, OI Lab, pre/post market planning, stock detail page, and learning section. The goal now is to **fix weak systems, remove confusion, improve trader usability, and make the website more decision-focused**.

Please focus on the following priorities:

## 1. Fix signal consistency

Some pages currently show mixed or confusing signals. For example, a page may show “Neutral” while the supporting indicators are mostly bearish, or say “call writers adding” when OI change is actually negative.

Please improve the signal engine so every recommendation clearly shows:

* Bias: Bullish / Bearish / Neutral / Range-bound
* Confidence percentage
* Timeframe: Intraday / Swing / Positional
* Reason for the signal
* Conflicting signals, if any
* Confirmation condition
* Invalidation condition

Example:

“Neutral-to-Bearish. Confidence 62%. Price is below short-term EMAs and breadth is weak, but MACD is improving. Avoid longs unless price reclaims resistance.”

## 2. Fix empty target and stop-loss boxes

On the stock page, target and stop boxes are currently blank in some cases. Please do not leave these empty.

If no trade setup is generated, show a proper message:

“No valid trade setup generated because risk/reward is not favorable.”

Or:

“Target and stop-loss will appear after breakout/breakdown confirmation.”

## 3. Improve data freshness and source clarity

Every important widget should clearly show:

* Data source: Kite / NSE / Yahoo fallback
* Last updated time
* Live / delayed / cached status
* Market open or closed status
* Warning when data is stale

The user should never be confused about whether the data is live, delayed, cached, or stale.

## 4. Improve Option Chain logic and layout

The Option Chain is powerful but needs cleanup.

Please implement:

* Sticky strike column
* Sticky table header
* Better horizontal scrolling
* Column show/hide settings
* Compact mode and Pro mode
* Saved user column preferences
* Clearer OI interpretation

Important logic fix:
If OI change is negative, do not say “writers adding.” Negative OI change usually means unwinding or reduction. Wording must correctly distinguish between:

* Fresh call writing
* Fresh put writing
* Call unwinding
* Put unwinding
* Short covering
* Long buildup
* Long unwinding
* Short buildup

## 5. Improve OI Lab interpretation

OI Lab is one of the strongest parts of the website, but it needs clearer trading interpretation.

Please add:

* PCR trend, not just current PCR
* OI wall shift tracker
* Support strengthening / weakening
* Resistance strengthening / weakening
* Max Pain warning tooltip
* IV skew explanation
* Alert when spot nears major OI wall
* Alert when OI wall shifts
* Alert when PCR crosses important levels

Max Pain should not be shown as a standalone trade signal. Add tooltip:

“Max Pain is not a trade signal by itself. It is more useful near expiry and should be checked with price action, OI change, volume, and IV.”

The main goal is to convert the website from a market-data dashboard into a **trading decision engine**.
