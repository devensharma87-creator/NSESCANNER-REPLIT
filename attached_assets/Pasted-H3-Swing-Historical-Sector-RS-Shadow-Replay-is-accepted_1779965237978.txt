## Outcome logic

For each replayed row:

1. Determine whether entry/trigger was reached:

```text
trigger_hit_daily = future high >= trigger_price or entry
```

2. Determine whether target1 was reached:

```text
target1_hit_daily = future high >= target1
```

3. Determine whether stop was reached:

```text
stop_hit_daily = future low <= stop_loss
```

4. If both target and stop occur in the same day:

Mark outcome as:

```text
ambiguous_same_day_stop_and_target
```

Do not assume which happened first.

5. If entry was never reached:

Mark:

```text
not_triggered
```

6. If entry reached and target hit before any stop ambiguity:

Mark:

```text
target1_hit_daily_approx
```

7. If entry reached and stop hit before target, where daily bars make it clear:

Mark:

```text
stop_hit_daily_approx
```

8. Also calculate forward returns from scan close:

* 1D return
* 3D return
* 5D return
* 10D return
* 20D return
* max favourable daily move
* max adverse daily move
