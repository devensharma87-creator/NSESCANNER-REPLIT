## What changed and why

### 1. Test infrastructure (new)

* `artifacts/api-server/vitest.config.ts` — coverage targets `src/lib/**/*.ts`, excludes I/O wrappers, 5 s test timeout.
* `artifacts/api-server/package.json` — adds `test`, `test:watch`, `test:coverage` scripts and `vitest` + `@vitest/coverage-v8` devDeps.
* `artifacts/api-server/tsconfig.json` already excludes `src/**/*.test.ts` from production build via `exclude` clause (verified).

### 2. Math/scoring fixes

**`src/lib/scoring.ts`**

* **Stop-loss inversion guard.** Previous code: `Math.max(support, price - …)` for BUY. If a fast breakdown pushed price below the lagging 20-day support, this would set the stop-loss *above* entry → inverted trade. Fix: cap at `price * 0.999` for BUYs, mirror at `price * 1.001` for SELLs.
* **Missing-indicator handling.** `adx ?? 20`, `volRatio ?? 1`, `deliveryPct ?? 50` substituted fake "neutral" values that biased every score toward zero on data-incomplete symbols. New behaviour: pass `null` through and skip the rule entirely. The score then honestly reflects only the rules with real evidence.
* **`confidence` field documented honestly.** It measures internal consistency of evidence, not predictive probability. Field name is preserved for API back-compat; the comment is the truth.

### 3. OpenAPI 3.1 sync

**`lib/api-spec/openapi.yaml`** — grew from 22 paths / 51 schemas to **55 paths / 86 schemas**. Added paths:

* Auth: `/auth/status`, `/auth/login`, `/auth/logout`
* Kite: `/kite/status`, `/kite/login-url`, `/kite/callback`, `/kite/logout`, `/kite/quote/{symbol}`, `/kite/quotes`, `/kite/subscribe`, `/kite/stream`
* Scan: `/scan/full-nse`, `/scan/full-nse/status`, `/scan/full-nse/export`
* Market: `/index/{slug}`, `/provider/status`
* Deepscan: `/deepscan/lookup`, `/deepscan/snapshot/{symbol}`
* Options: `/options/chain/{underlying}/export`
* OI Lab: `/options/oi-lab/universe`, `/options/oi-lab/snapshot`, `/options/oi-lab/heatmap`, `/options/oi-lab/heatmap/export`, `/options/oi-lab/insights/{underlying}`, `/options/oi-lab/tracker/start|stop|status|series|export`
* News/system: `/stocks-to-watch`, `/security/audit`, `/system/status`
* TradingView: `/webhooks/tradingview` (POST/GET/DELETE)

Spec validates against `openapi-spec-validator` (3.1.0).

### 4. customFetch credentials default

**`lib/api-client-react/src/custom-fetch.ts`**

* `credentials: "include"` is now applied by default. Pre-fix, the orval-generated TanStack Query hooks never set `credentials`, so the browser defaulted to `"same-origin"` — which silently 401'd the moment the API and SPA were served from different subdomains.
* New `setCredentialsMode(...)` lets Expo/Bearer-token deployments opt out.
* Re-exported `setCredentialsMode`, `ApiError`, `ResponseParseError`, plus types `CustomFetchOptions`, `ErrorType` from `@workspace/api-client-react`.

### 5. Auth tightening

**New table — `lib/db/src/schema/userSession.ts`**

```sql
CREATE TABLE user_session (
  id           TEXT PRIMARY KEY,                    -- 64-char hex session ID
  csrf_token   TEXT NOT NULL,                       -- 48-char hex double-submit token
  created_at   TIMESTAMPTZ NOT NULL DEFAULT now(),
  last_seen_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  expires_at   TIMESTAMPTZ NOT NULL,
  ip           TEXT,
  user_agent   TEXT
);
```

Run `pnpm -F @workspace/db db:push` to create it.

**`src/lib/auth.ts`** — full rewrite, public surface preserved:

* `createSession(req, res)` — persist row, set signed httpOnly cookie carrying the 64-char ID.
* `loadSession(req)` — DB lookup; returns `null` on missing/expired. Slides `expiresAt` forward (throttled to 1 write/min).
* `destroySession(req, res)` — delete row + clear cookie. **Server-side revocation** of stolen cookies.
* `requireCsrf` middleware — compares `X-CSRF-Token` header against `req.session.csrfToken`. GET/HEAD/OPTIONS pass through. Apply after `requireAuth`.
* `reapExpiredSessions()` — bulk DELETE of past-expiry rows. Called on boot + hourly, `.unref()` on the timer.
* Legacy `setSessionCookie`/`clearSessionCookie`/`isAuthenticated` shims kept for back-compat during incremental migration of routes.

**`src/routes/auth.ts`**

* `/auth/status` now returns `csrfToken` and `expiresAt` to authenticated callers (so the SPA can echo the token on mutating requests).
* `/auth/login` returns the new session's `csrfToken` directly.

**`src/lib/kiteAuth.ts`**

* `next6amIST` rewritten to use `Intl.DateTimeFormat({ timeZone: "Asia/Kolkata" })`. Prior implementation manually added 5.5 hours to UTC — works for India today (no DST) but brittle. New version is DST-safe and unit-tested at the exact 06:00 IST boundary, including the strict-future invariant.
* Exposed via `__testing.next6amIST` for unit tests.

**`src/app.ts`**

* CORS allowlist driven by env var `CORS_ORIGINS` (CSV). Replaces the previous `origin: true` reflective behaviour. Same-origin requests (no Origin header) always allowed; set `CORS_ORIGINS=*` for the legacy "reflect any origin" if needed for development.
* CSP enabled via helmet defaults: `script-src 'self'`, `style-src 'self' 'unsafe-inline'` (Radix needs inline styles), `img-src 'self' data: blob:`, `frame-ancestors 'self'`, `object-src 'none'`. Was disabled.
* `cross-origin-opener-policy` and `referrer-policy: strict-origin-when-cross-origin` added.
* Session reaper interval `.unref()`d.
* Global error handler now `res.destroy()`s a half-streamed connection on mid-flight error instead of leaking it.
* `requireCsrf` wired in after `requireAuth`.

### 6. OI Lab fixes

**`src/lib/oiLab.ts`**

* **Max-pain tie-breaker.** Previous: `if (pain < minPainVal)` — strict less-than meant ties resolved on Map iteration order. Fixed to prefer the strike closest to spot.
* `classifyBuildup` cleaned up with explicit four-quadrant comments and the early-return logic flattened.
* `__testing` export of `classifyBuildup`, `scoreSentiment`, `bandFromScore` for unit tests.

### 7. Documentation

* **`README.md`** (new, top-level). Repo layout, setup, env vars, operational topics (auth, CORS, Kite daily expiry, rate limits, TradingView webhooks), API spec link, architecture highlights, roadmap.
* **`.env.example`** (new, top-level). Full inventory of all 9 env vars the code reads (`PORT`, `NODE_ENV`, `LOG_LEVEL`, `DATABASE_URL`, `SESSION_SECRET`, `APP_ACCESS_PASSWORD`, `CORS_ORIGINS`, `KITE_API_KEY`, `KITE_API_SECRET`, `TRADINGVIEW_WEBHOOK_SECRET`) with required/optional status and one-line rationale each.

## What this delivery does NOT include (still on the roadmap)

These were in the original review but didn't fit the hands-on session:

* `/metrics` Prometheus endpoint with counters for scans completed, Yahoo retries, Kite reconnects, IV-solve failures, RSS feed failures.
* Sentry-style error reporter for the SPA.
* Backtest harness for the scoring engine (calibrate weights/cutoffs against forward returns).
* SSE/WebSocket push from Kite to the SPA dashboard (currently 30s polling).
* Versioned Drizzle migrations (currently `db:push` workflow).
* Streaming variant of the full-NSE-scan response for mobile.
* Dependabot/Renovate config for the 80+ Radix UI dependency tree.
* Migrating bespoke `fetch()` calls in `oi-lab.tsx`, `audit.tsx`, `status.tsx`, `scanner.tsx` to the orval-generated hooks (now that the OpenAPI spec covers them).
