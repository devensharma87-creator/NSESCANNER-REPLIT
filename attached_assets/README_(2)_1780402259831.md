# Charting — Trading Terminal Tab

A self-hosted, broker-grade charting tab powered by **your Zerodha Kite Connect** account, with a full custom-indicator + signal engine. Drops into your website as one tab.

## What you get
- TradingView Lightweight-Charts engine (the same renderer TradingView open-sources)
- **Candlestick + Line** chart types, all timeframes (1m → 1W)
- **Live data** via Kite WebSocket ticker (LTP updates the forming candle in real time)
- Every NSE/BSE **index + script** (full Kite instrument master, searchable)
- **Global indices** (S&P 500, Dow, Nasdaq, FTSE, Nikkei, Hang Seng, DAX, CAC) via a pluggable feed
- Indicators: **EMA 11/20/50/100/200**, **VWAP** (session-anchored), **RSI 14**, **Volume bars**
- **Smart Suite** (one toggle): Fixed-range **Volume Profile** (POC / VAH / VAL), **Support & Resistance** zones, **FVG** (fair value gaps), **SMC** (BOS / CHoCH / Order Blocks)
- **Auto trade signals** — confluence scoring (EMA stack + VWAP + RSI + momentum cross), cooldown-spaced, star-rated, streamed to a live feed

## Setup
1. `cd backend && npm install`
2. Copy `.env.example` → `.env`, fill `KITE_API_KEY` / `KITE_API_SECRET`
3. In your Zerodha developer console, set the **redirect URL** to `http://localhost:8080/api/callback` (or your domain)
4. `npm start`
5. Open `http://localhost:8080` → click **Connect Zerodha** → approve → charts go live

To embed as a tab in your existing site: serve the `frontend/` folder from your app (or iframe `index.html`), and point `app.js`'s `API` constant at your backend origin. Since you already have Zerodha integrated, you can reuse your existing access_token — just set `state.accessToken` in `server.js` from your session store instead of the login flow.

## Things you didn't ask for but a high-end chart needs (added)
- **Confluence scoring + cooldown** on signals so you don't get spammed on every bar
- **CHoCH vs BOS distinction** (trend continuation vs reversal) — critical for SMC
- **Value Area (70%) calc** around POC, not just POC line
- **Session-anchored VWAP** that resets daily (intraday-correct, not a running average)
- **Trend badge** (live up/down/neutral from market structure)
- **Pluggable global feed** so you're not locked to one vendor
- **Auto-reconnect-friendly WS** and tick→candle merge logic
- Graphful **"no data" toasts**, mobile-responsive collapse

## Recommended next hardening (production)

## Important note on "connect to my TradingView account"
TradingView's embeddable widgets do **not** let a site log into a user's TradingView account or run custom Pine indicators via embed — that's by their design/ToS. Your custom suite (SMC/FVG/VP/signals) therefore runs on **your own data + engine** here, which is what makes it fully yours and customizable. If you also want the familiar TradingView UI for plain charting, you can add their free Advanced Chart widget alongside this — but it won't carry your custom indicators or your Zerodha order flow.
