====================================================
WHY THIS PHASE IS REQUIRED
====================================================

The audit reports found a major F&O signal honesty issue:

1. NIFTY / BANKNIFTY / SENSEX index candles may carry zero volume.
2. sessionVwap currently degrades to HLC3 when volume is zero.
3. Therefore signal drivers labelled as VWAP are not true VWAP.
4. Volume Profile may return fake/degenerate VAH / VAL / POC when all volumes are zero.
5. These fake VWAP / VP values can affect F&O signal confidence and displayed signal cards.
6. Volume breakout may be structurally dead for indices.
7. Mean reversion may be near-impossible when VWAP degenerates.
8. Signal cards may show fabricated VWAP / VAH / VAL / POC values.

This phase must make the system honest and fail-closed where volume is unavailable.

====================================================
PART B — DESIGN DECISION
====================================================

Implement the safe honesty-first design.

Default rule:

If volume is unavailable or cumulative volume is zero, VWAP and Volume Profile must be treated as unavailable, not approximated.

Required behavior:

1. sessionVwap must not silently return HLC3 as VWAP when total volume is zero.
2. volumeProfile must return null when total volume is zero or non-positive.
3. Signal context must carry explicit flags/reasons:
   - vwapAvailable
   - vwapUnavailableReason
   - volumeProfileAvailable
   - volumeProfileUnavailableReason
   - volumeSource
4. F&O signal cards must not show VWAP / VAH / VAL / POC if unavailable.
5. Driver text must not say “above VWAP” if VWAP is unavailable.
6. Detectors dependent on VWAP/volume profile must either:
   - skip that driver honestly, or
   - emit a clear suppressed reason such as INDEX_VOLUME_UNAVAILABLE.
7. No fake replacement value is allowed.

Acceptable unavailable reasons:

- ZERO_VOLUME_INDEX_CANDLE
- VOLUME_UNAVAILABLE
- VOLUME_PROFILE_UNAVAILABLE_ZERO_VOLUME
- VWAP_UNAVAILABLE_ZERO_VOLUME
- FUTURES_VOLUME_NOT_WIRED_TO_SIGNALS

====================================================
PART D — DETECTOR HANDLING
====================================================

For each detector, implement honest behavior:

1. TREND_CONTINUATION

If VWAP unavailable:
- do not add “Spot above VWAP” confidence driver.
- do not use fake HLC3.
- either score using remaining non-volume factors or demote if VWAP is mandatory.
- add reason: VWAP_UNAVAILABLE_ZERO_VOLUME.

2. VWAP_RECLAIM

If VWAP unavailable:
- do not run this detector as VWAP reclaim.
- suppress with clear reason.
- do not relabel a candle reversal as VWAP reclaim.

3. MEAN_REVERSION

If VWAP unavailable:
- do not calculate distance from fake VWAP.
- suppress with clear reason.

4. VOLUME_BREAKOUT

If volume is zero/unavailable:
- suppress with clear structural reason.
- do not show generic “conditions not met” only.

5. BASELINE

If VWAP unavailable:
- remove VWAP vote from denominator or mark unavailable.
- do not count fake VWAP vote.
- ensure confidence formula does not reward fake alignment.

6. CONFLUENCE ENGINE

If Volume Profile unavailable:
- no VP factor.
- no fake “above value area” bullish boost.
- no fake “above POC” driver.
- no VAH/VAL/POC output.
