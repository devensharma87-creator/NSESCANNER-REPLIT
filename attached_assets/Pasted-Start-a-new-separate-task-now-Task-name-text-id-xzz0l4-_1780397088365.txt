# Phase 3 — Candidate rules to evaluate

Evaluate these rules using replay evidence.

## Rule A — Premium hard stop backstop

For long option paper trades:

```text id="pgocgv"
if last_premium <= stop_premium:
    close paper trade as STOPPED
```

Purpose:

```text id="z1tew1"
Defense-in-depth when premium collapses faster than spot lifecycle or when spot lifecycle misses.
```

This must not replace spot stop logic. It is a backstop.

---

## Rule B — Profit protection arming

Calculate:

```text id="uojexw"
premiumRisk = entryPremium - stopPremium
premiumGain = currentPremium - entryPremium
mfePremium = maxPremiumSeen - entryPremium
```

Candidate arming conditions:

```text id="q4whx0"
Arm protection at +0.75R
Arm protection at +1R
Arm protection at +20% premium gain
Arm protection at +25% premium gain
```

Replay all and recommend which one is best.

Do not randomly choose.

---

## Rule C — Breakeven protection

Once protection is armed:

```text id="r9foch"
If premium falls back to entryPremium or slightly above entryPremium, close to prevent winner becoming loser.
```

Candidate close levels:

```text id="h82hfl"
entryPremium
entryPremium + 0.1R
entryPremium + 5% premium
```

Replay and recommend.

---

## Rule D — Max giveback protection

If MFE is strong:

```text id="smygau"

    close to protect profit
```

Replay:

```text id="vzzb2v"

50% giveback
60% giveback
```

Choose the least overfitted practical rule.
