## Step 3 — DB coverage query

Run read-only query:

```sql
SELECT scan_date,
       COUNT(*) AS total,
       COUNT(intraday_last) AS with_ltp,
       COUNT(intraday_updated_at) AS with_intraday_ts,
       COUNT(*) FILTER (WHERE trigger_hit = true) AS trigger_hits,
       MAX(intraday_updated_at AT TIME ZONE 'Asia/Kolkata') AS latest_refresh_ist
FROM swing_scan_result
GROUP BY scan_date
ORDER BY scan_date DESC
LIMIT 5;
```

Acceptance expectation:

* latest available `scan_date` should start getting `intraday_last`,
* `intraday_updated_at` should be populated,
* `latest_refresh_ist` should be during current live session,
* errors should be zero or clearly explained.

## Step 5 — Latch verification

Find any rows where trigger condition is currently met.

Use:

```sql
SELECT symbol, scan_date, action, score, close_price,
       trigger_price, entry, intraday_last,
       trigger_hit, intraday_updated_at
FROM swing_scan_result
WHERE scan_date = (SELECT MAX(scan_date) FROM swing_scan_result)
  AND intraday_last IS NOT NULL
  AND trigger_price IS NOT NULL
ORDER BY intraday_updated_at DESC
LIMIT 50;
```

Verify:

* once `trigger_hit = true`, it does not revert to false,
* rows already latched remain latched,
