5. Data Difference Calculation

For every numerical field, calculate difference as:

absolute_difference = production_value - live_value
percentage_difference = absolute_difference / live_value * 100

Classify tolerance:

0% to 0.10% = acceptable
0.10% to 0.50% = minor
0.50% to 1.00% = warning
Above 1.00% = material issue
Above 3.00% = critical issue

For fast-moving intraday data, compare only if timestamps are close.

Timestamp rule:

If production timestamp and live timestamp difference > 60 seconds:
  mark as STALE_TIMESTAMP_DIFFERENCE

For EOD data:

If date mismatch exists:
  mark as STALE_EOD_DATA
