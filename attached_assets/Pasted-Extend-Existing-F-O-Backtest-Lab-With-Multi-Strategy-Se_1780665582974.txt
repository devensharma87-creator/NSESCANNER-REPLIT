Data Quality Guardrails

Keep the original strict guardrails.

The existing prompt already says not to break existing features, not to fabricate historical options data, not to use future candles, not to mix legacy with official engine, and not to place live orders. Keep all of that unchanged.

Additional rules:

If real historical option premium data is available:
- calculate tradable option P&L.

If only index candle data is available:
- allow signal-quality backtest only.
- do not show option premium P&L.
- mark result as "Index signal validation only".
- show clear warning.

If option chain data is missing:
- disable option-chain confirmation automatically.
- show warning.

If data quality is poor:
- allow user to view signals but mark performance as partial/unreliable.
UI Warning Text
