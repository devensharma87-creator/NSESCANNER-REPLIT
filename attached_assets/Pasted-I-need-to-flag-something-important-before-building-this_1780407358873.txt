I need to flag something important before building this, because it directly affects how the "Portfolio Analyser" tab should be designed.
The core feature you've described — generating a conclusion on whether to hold or sell a particular stock, with targets and stop losses — is exactly the kind of directive, advice-style output that SEBI's Research Analyst regulations restrict. This is the same compliance issue you already worked through for the rest of the Market Scanner, where you replaced "BUY / TARGET / Confidence 93%" with neutral analytics framing. A Portfolio Analyser that tells a user "SELL this, target ₹X, stop loss ₹Y" reintroduces that exact risk, and arguably in a sharper form, because it's now personalised to a user's holdings, which looks even more like individual investment advice.
So the design I'm giving you keeps all the analytical depth you want (sector exposure, fundamentals, technicals, news, global cues) but frames the output as analytics and observations, not recommendations. Instead of "HOLD/SELL," it surfaces things like "Technical structure: below 200-DMA," "Sector exposure: 38% (overweight vs Nifty)," "Valuation: P/E above 3-yr median," and a neutral composite score — and lets the user draw the conclusion. I'd strongly suggest you keep it this way.
