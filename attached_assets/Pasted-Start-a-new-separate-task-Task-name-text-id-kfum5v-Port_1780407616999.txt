# Formula correctness

Implement these formulas correctly:

```text id="6wr195"
Invested Value = Qty * Rate
Current Value = Qty * CMP
Day Change = Qty * (CMP - Previous Close)
Day % Change = ((CMP - Previous Close) / Previous Close) * 100
Total Return = Current Value - Invested Value
Total Return % = (Total Return / Invested Value) * 100
Portfolio Weight % = (Current Value / Total Portfolio Current Value) * 100
```

Important:

```text id="zhcc3i"
Do NOT calculate Total Return as Invested Value - Current Value.
That is wrong.
```
