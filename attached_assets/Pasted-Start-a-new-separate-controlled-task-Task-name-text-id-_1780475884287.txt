# Part 3 — Correct XIRR / annualised return label

Do not mislabel average-cost returns as XIRR.

Rule:

```text id="8kxndh"
If only single purchase date + avg rate are available:
  show Annualised Return Estimate, not XIRR.

If transaction-level cashflows exist:
  show XIRR.

If dividends/realised exits are missing:
  show XIRR unavailable / requires transaction history.
```

Add explanation tooltip:

```text id="kfi90z"
XIRR requires dated cashflows such as buys, sells, and dividends. With only average price and one purchase date, the system shows an annualised return estimate.
```

# Part 5 — Verify Day P&L formula

Confirm Day P&L uses previous close, not average cost.

Formula:

```text id="lm2295"
Day P&L = Qty * (CMP - Previous Close)
Day % Change = ((CMP - Previous Close) / Previous Close) * 100
```

Total P&L:

```text id="ftw3xn"
Total P&L = Current Value - Invested Value
```

Add tests to prevent formula regression.
