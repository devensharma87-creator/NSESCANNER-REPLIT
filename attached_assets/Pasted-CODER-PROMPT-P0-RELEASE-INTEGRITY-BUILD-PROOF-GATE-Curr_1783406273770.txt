FINAL VERDICT
====================================================

Final verdict must be exactly one:

- RELEASE_INTEGRITY_PROD_VERIFIED
- RELEASE_INTEGRITY_DEV_VERIFIED_BUILD_PENDING
- RELEASE_INTEGRITY_PARTIAL_GAP_REMAINS
- RELEASE_INTEGRITY_BUILD_NOT_DEPLOYED
- ROLLBACK_REQUIRED

Use RELEASE_INTEGRITY_PROD_VERIFIED only if build-info, frontend markers, release verification script, and production checks all pass.

Use RELEASE_INTEGRITY_DEV_VERIFIED_BUILD_PENDING if implementation/tests pass but production publish is pending.

Use RELEASE_INTEGRITY_PARTIAL_GAP_REMAINS if build-info exists but frontend/backend proof is incomplete.

Use RELEASE_INTEGRITY_BUILD_NOT_DEPLOYED if production still serves the old build.

Use ROLLBACK_REQUIRED if secrets leak, broker execution turns on, real orders are placed, stale/report-grade data can drive trades, Telegram spam returns, or destructive migration occurs.
