====================================================
PHASE 1 — DESIGN REPORT-GRADE MARKET DATA CONTRACT
====================================================

Create a report-grade contract inside the marketData layer.

Suggested type:

type MarketDataUseCase =
  | "TRADE_DECISION"
  | "PAPER_TRADE"
  | "LIVE_ALERT"
  | "REPORT_POST_MARKET"
  | "REPORT_PRE_MARKET"
  | "DISPLAY_ONLY";

Suggested report-grade index quote type:

type ReportGradeIndexQuote = {
  symbol: "NIFTY" | "BANKNIFTY" | "SENSEX" | string;
  ltp: number | null;
  open: number | null;
  high: number | null;
  low: number | null;
  close: number | null;
  previousClose: number | null;
  change: number | null;
  changePct: number | null;
  source: "KITE" | "WAREHOUSE" | "CACHE" | "UNAVAILABLE";
  sourceAsOf: string | null;
  freshnessSec: number | null;
  tradeGrade: false;
  reportGrade: boolean;
  canDriveSignals: false;
  canDrivePaperTrades: false;
  canDriveReports: boolean;
  marketSession: "open" | "closed" | "post_market" | "unknown";
  reason: string | null;
};

Rules:

1. Report-grade quote may be acceptable after market close.
2. Report-grade quote must never be trade-grade.
3. Report-grade quote must never drive signals or paper trades.
4. Post-market quote can accept market-close snapshot/tick if sourceAsOf is after or near market close.
5. It must carry source/as-of/freshness.
6. If data is too old even for report-grade, return unavailable with reason.
7. Do not weaken strict router.getIndexQuotes() used for trading.

PHASE 2 — IMPLEMENT MARKETDATA FACADE
====================================================

Add repo-appropriate function inside marketData layer, for example:

getReportGradeIndexQuotes(input)

or:

getIndexQuotesForReport({ reportType: "POST_MARKET" })

It may internally call the same Kite provider, but dailyReports.ts must import only from the marketData layer, not from raw provider modules.

Expected behavior:

1. During market open:
   - returns fresh Kite quote
   - reportGrade true
   - tradeGrade false unless caller explicitly asks trade path elsewhere

2. Post-market around 15:45:
   - accepts latest close snapshot even if older than 10 minutes
   - labels sourceAsOf/freshnessSec
   - reportGrade true
   - tradeGrade false
   - canDriveReports true
   - canDriveSignals false
   - canDrivePaperTrades false

3. Too stale / no data:
   - reportGrade false
   - canDriveReports false
   - reason = REPORT_INDEX_QUOTES_STALE or INDEX_QUOTES_UNAVAILABLE

4. Market closed / Saturday:
   - do not pretend live quote
   - either return last available report-grade quote with as-of, or unavailable honestly
   - never fake live data
