P1B — MACD WARM-UP FIX

====================================================
PURPOSE
====================================================

Fix MACD warm-up honesty and correctness.

The P1 consolidated audit found that the canonical NSE indicator implementation may compute the MACD signal EMA using zero-filled null MACD values:

macdLine.map(v => v ?? 0)

This can distort early MACD signal/histogram values for new listings or short-history symbols.

The global indicator implementation reportedly already seeds MACD signal EMA from the first valid MACD value, which is more correct.

Goal:

1. Confirm the current MACD warm-up behavior.
2. Fix only the canonical MACD warm-up if the audit finding is correct.
3. Preserve output shape/length.
4. Return null values until enough valid data exists.
5. Add tests proving early MACD values are not zero-seeded.
6. Do not change scoring weights, signal thresholds, or trade logic.

====================================================
PART C — EXPECTED CORRECT MACD BEHAVIOR
====================================================

Implement correct behavior:

1. MACD line should be null until enough data exists for fast/slow EMA.
2. Signal line should be computed only from valid MACD values.
3. Signal EMA must not be trained on fake zeros.
4. Histogram should be null until both MACD and signal are valid.
5. Output array length must remain equal to input close array length.
6. Existing public API shape must remain compatible.
7. For long-history series, values after warm-up should remain stable except minor expected differences caused by correct seeding.
8. For short-history/new listing series, distorted early signals must be removed.

Preferred implementation pattern:

- Find first valid MACD index.
- Slice valid MACD values from that index.
- Compute signal EMA on valid MACD values only.
- Re-pad signal array with nulls before first valid signal.
- Compute histogram only when MACD and signal are both non-null.

Do not use:

macdLine.map(v => v ?? 0)

for signal EMA seeding.
