Telegram API:

`https://api.telegram.org/bot<token>/sendMessage`

Payload:

* `chat_id`
* `text`
* `parse_mode` optional
* `disable_web_page_preview: true`

Timeout:

* 5 seconds max

Retry:

* no infinite retry
* at most 1 retry for transient network failure
* no retry for invalid token/chat id

Failure behaviour:

* log safe error code only
* do not throw to caller
* do not block F&O cycle
