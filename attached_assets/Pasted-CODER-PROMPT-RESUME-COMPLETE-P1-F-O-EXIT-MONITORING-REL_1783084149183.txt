- quoteSource
- quoteAsOf
- quoteFreshnessSec
- tradeGrade
- blocked
- blockedReason
- priorityRuleApplied

Required rules:

2. No Yahoo/proxy/cache/synthetic exit.

11. Quote timestamp must be captured.
12. Exit price must be the quote price actually used.

If this already exists, verify it. If incomplete, complete it.

PHASE 3 — VERIFY OR COMPLETE DB IDEMPOTENCY
====================================================

Closing a paper trade must be atomic.

Use actual schema/table names, but the pattern must be equivalent to:

UPDATE paper_trade_fo
SET status = 'CLOSED',
    exit_reason = ...,
    exit_price = ...,
    closed_at = now(),
    updated_at = now()
WHERE id = ?
  AND status = 'OPEN'
RETURNING *

Required:

1. Only OPEN trades can close.
2. Already closed trades cannot close again.
3. Concurrent monitors cannot double close.
4. Failed Telegram does not reopen trade.
5. Retry does not duplicate Telegram.
6. Every close has audit fields.

Audit fields should include, if not already present:

- exit_detected_at
- exit_quote_source
- exit_quote_as_of
- exit_quote_freshness_sec
- exit_trade_grade
- exit_monitor_status

- last_exit_check_error
- exit_notification_status

Use safe additive schema changes only.

No destructive migration.
