```ts
type EquityPaperTradeSource =

  | "SWING_STAGED_APPROVAL"
  | "MANUAL_BUY"
  | "MANUAL_STAGE_APPROVAL"

Create or formalize lifecycle link:

  paperTradeId: string;
  symbol: string;
  source: EquityPaperTradeSource;
  decisionAuditId: string | null;
  stagedOrderId: string | null;
  signalId: string | null;
  telegramNotificationId: string | null;
  createdBy: "AUTO" | "OWNER" | "SYSTEM" | "LEGACY";

  lifecycleStatus: string;

  updatedAt: string;
};

Rules:

Every new equity paper trade must have a source.

Do not guess legacy source silently.
Do not backfill uncertain history as if confirmed.
