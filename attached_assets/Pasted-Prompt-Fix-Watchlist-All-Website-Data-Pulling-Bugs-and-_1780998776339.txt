Phase 3: Fix Symbol Normalization

This is likely one major bug.

Create a single symbol normalization layer.

Required mappings:

UI symbol: RELIANCE
NSE quote symbol: RELIANCE
Yahoo symbol: RELIANCE.NS
Kite instrument symbol: match Kite instrument master correctly
Display name: Reliance Industries

Sensex 30 is a BSE index, but most constituents are also NSE-listed. For quote fetching, use NSE symbols unless BSE quote support is explicitly implemented and tested.

Make sure symbols are not wrongly passed as:

NSE:RELIANCE to a provider that expects RELIANCE
RELIANCE.NS to a provider that expects plain NSE symbol
company name instead of trading symbol
lowercase symbol
symbol with spaces
old/invalid instrument token

Create functions like:

normalize_symbol_for_provider(symbol, provider)
resolve_instrument(symbol, exchange="NSE")
to_yahoo_symbol(symbol)
to_display_symbol(symbol)

All quote paths must use this shared normalization logic.
