PART B — CANONICAL INDEXQUOTEFACT
====================================================

Implement a canonical shared object:

IndexQuoteFact

Required fields:

- symbol
- displayName
- exchange
- instrumentToken
- ltp
- prevClose
- changePts
- changePct
- open
- high
- low
- dayVolume, if valid
- source
- asOf
- fetchedAt
- freshnessSeconds
- tradeGrade
- provider
- unavailableReason
- canonicalCloseDate
- quoteSessionDate

Rules:

1. `changePts = ltp - prevClose`
2. `changePct = ((ltp - prevClose) / prevClose) * 100`
3. This prevClose baseline must be used everywhere.
4. If any view wants open-baseline, it must be separate and labelled `vs open`.
5. No page may recompute changePct independently from raw ltp/open/prevClose.
6. No page may mix a quote from one symbol with analytics from another symbol unless scale validation passes.
7. asOf must be tick timestamp of displayed value, not fetch time.
8. source/freshness/tradeGrade must travel with the object.

Consumers must be migrated to use IndexQuoteFact, not local calculations.

At minimum migrate:

1. Home index board.
2. Pro Market / Market Analyzer index cards.
3. Deep Scan index context.
4. Option Chain spot header.
5. OI Lab spot header.
6. F&O Intraday Signal spot header.
7. F&O signal card index header.
8. Any report/export using index prevClose/changePct.

PART C — ANALYTICS SCALE GUARD / PROXY BLOCK
====================================================

Implement analytics validation before rendering price-level widgets.

Analytics may include:

- prev OHLC
- pivots
- support/resistance levels
- EMAs
- 52W low/high
- range position
- floor pivot distance
- EMA-vs-price comparison

Rules:

1. If analytics provider symbol != quote symbol, validate scale.
2. If abs(analytics.prevClose - quote.prevClose) / quote.prevClose > 1%, suppress analytics.
3. If ltp is outside 52W low/high, suppress 52W band and range position.
4. If abs(pivot - ltp) / ltp > 5%, suppress pivot levels and emit warning.
5. Proxy data may feed dimensionless indicators only:
   - RSI
   - ADX
   - percentage returns
   - volatility percentages
6. Proxy data must not feed absolute price-level widgets:
   - pivots
   - EMAs vs price
   - previous OHLC
   - 52W band
   - range position
   - support/resistance levels
7. UI should render:
   “— · proxy blocked: level scale mismatch”
   or:
   “analytics unavailable — source scale mismatch”

Acceptance fixtures must include:

1. FINNIFTY contaminated prevClose / 52W example.
2. MIDCAP Select LTP 14618 with Midcap 50 pivot around 17845.
3. LTP below displayed 52W low.
4. Valid same-scale analytics that should render normally.
