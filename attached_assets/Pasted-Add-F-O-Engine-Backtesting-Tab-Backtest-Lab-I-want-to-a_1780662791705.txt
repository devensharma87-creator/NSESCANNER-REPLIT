Add F&O Engine Backtesting Tab — “Backtest Lab”

I want to add a new separate tab to the website named Backtest Lab.

This tab should allow me to backtest the existing official F&O engine using historical data for up to 2 years, without disturbing any current live/paper-trading features, existing F&O engine logic, swing engine, portfolio, reports, database, or UI flow.

This is a serious engine-validation feature, not just a dummy report table. The backtest must replay historical market conditions candle-by-candle and show what trades the engine would have taken based only on data available at that time. There must be no look-ahead bias, no fake trades, no synthetic result generation, and no hidden assumptions.
