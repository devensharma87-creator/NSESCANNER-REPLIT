VIX-based position sizing — pulls India VIX (default NSE:INDIAVIX) via request.security and scales lots into three bands: calm market (VIX ≤ 13) → 3 lots, mid band → 2 lots, high vol (VIX ≥ 20) → 1 lot. Live VIX value and current qty show in the table.

Configurable time windows — the lunch block and square-off are now input.session fields ("1200-1330" and "1500-1530" by default) instead of hardcoded minutes. Change them by editing the session strings; both can be toggled off entirely. Session-based is cleaner than the old minute-math and respects the chart's exchange timezone automatically.

Date-range filter — toggle "Limit backtest to date range" and set start/end dates to isolate a period (e.g. test only high-volatility months, or exclude an anomalous event). Off by default so it backtests everything.

Two specific cautions for v2:

VIX sizing affects backtest realism more than you'd expect. Because request.security on daily VIX returns the confirmed daily close, intraday it uses the prior day's VIX until today's close forms — which is actually what you want (no lookahead), but means the size for a given day is set by yesterday's VIX. That's realistic, just be aware of it when reading results.
Backtest the futures contract, not spot, and remember the ₹20 commission still understates real F&O costs — same caveat as v1.
