P1 — KITE OI UNIT VERIFICATION AGAINST NSE

====================================================
PURPOSE
====================================================

This is a verification-only audit.

The audit reports flagged that Kite option-chain OI unit interpretation may be unverified.

The platform currently needs to confirm whether Kite option-chain OI values are:

1. contracts, or
2. quantity units / shares, or
3. already lot-adjusted, or
4. source-dependent / inconsistent.

This matters because GEX, OI notional, OI concentration, flip zones, option-chain analytics, and any displayed rupee notional may be inflated if the platform multiplies by lot size when Kite OI is already in units.

The goal is to compare live Kite OI against NSE official option-chain OI for the exact same:

- underlying,
- expiry,
- strike,
- CE / PE side,
- timestamp,
- lot size.
