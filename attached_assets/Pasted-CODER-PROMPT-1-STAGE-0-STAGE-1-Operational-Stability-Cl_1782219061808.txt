PART A — KITE SESSION READINESS + PRE-OPEN SAFEGUARD
Root problem: Kite token expires daily at 06:00 IST (next6amIST() in lib/kiteAuth.ts). There is no pre-open check and no auto-relogin. On 2026-06-23 login happened at 15:21, so the whole session ran blind.
A.1 — Central readiness service. Create lib/kiteReadiness.ts exporting getKiteReadiness(): Promise<KiteReadiness>. Build it on top of existing functions — do not duplicate their logic:

session: getActiveSession() from lib/kiteAuth.ts
feed: feedStatus() from lib/kiteFeed.ts
market session: computeMarketStatus(now) from lib/marketEvents.ts (returns "open" | "closed" | "pre_open" — reuse it, do not reimplement IST math)

Return this exact shape:
tsinterface KiteReadiness {
  state: KiteReadinessState;          // see enum below
  severity: "ok" | "info" | "warn" | "critical";
  sessionPresent: boolean;
  sessionValid: boolean;
  loginTime: string | null;           // ISO
  expiresAt: string | null;           // ISO
  kiteOfflineSince: string | null;    // ISO; persisted, see A.3
  marketSession: "open" | "closed" | "pre_open";
  isPreOpenWindow: boolean;           // 08:45–09:15 IST
  feedConnected: boolean;             // feedStatus().connected
  feedRunning: boolean;               // feedStatus().running
  userActionRequired: boolean;        // true when owner must reconnect
  checkedAt: string;                  // ISO now
}

type KiteReadinessState =
  | "KITE_READY"
  | "KITE_EXPIRES_SOON"               // valid but < 30 min to 06:00 expiry
  | "KITE_EXPIRED"
  | "KITE_OFFLINE_PREOPEN"            // expired/missing during 08:45–09:15
  | "KITE_OFFLINE_MARKET_HOURS"      // expired/missing during 09:15–15:30
  | "KITE_CONNECTED_BUT_FEED_STALE"; // session valid but feed disconnected
State precedence (evaluate top-down, first match wins):

No/expired session + market open → KITE_OFFLINE_MARKET_HOURS (critical)
No/expired session + isPreOpenWindow → KITE_OFFLINE_PREOPEN (critical)
No/expired session otherwise → KITE_EXPIRED (warn)
Valid session + feed not connected during market open → KITE_CONNECTED_BUT_FEED_STALE (warn)
Valid session + < 30 min to expiry → KITE_EXPIRES_SOON (info)
Otherwise → KITE_READY (ok)
