====================================================
OBJECTIVE
=========

Build a professional swing cash staging workflow so valid swing opportunities can be captured quickly without blind automation.

The system should:

1. Take a validated swing candidate.
2. Re-run the Phase 1 risk gates.
3. Create a staged order if all gates pass or require review.
4. Show it in an approval queue.
5. Let the owner approve/reject/watch/expire quickly.
6. Recheck data before approval.
7. Track missed opportunities.
8. Keep broker execution hard-disabled.
9. Keep current swing logic unchanged.

Final target after this task:

`LIVE_DRY_RUN_READY`

or

`STAGED_APPROVAL_READY_BUT_BROKER_DISABLED`

No real order should be placed.
