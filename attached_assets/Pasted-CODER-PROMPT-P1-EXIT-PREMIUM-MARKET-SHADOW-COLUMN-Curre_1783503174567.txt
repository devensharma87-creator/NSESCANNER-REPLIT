====================================================
WHY THIS PHASE IS REQUIRED
====================================================

Current F&O paper trade exits use frozen/projected premium settlement for realized P&L.

This is acceptable as a directional-accuracy ledger, but not enough to prove real option-market P&L.

We now need a decision-neutral shadow field:

exit_premium_market

This should capture the nearest available real market option premium at exit time from trusted option-chain/Kite source, without changing exit decisions.

Purpose:

1. Compare frozen/projected exit premium vs actual market premium.
2. Measure paper-P&L realism gap.
3. Quantify theta/gamma/IV/slippage difference.
4. Improve future confidence in F&O paper reports.
5. Do not change trading decisions yet.

====================================================
PART C — CAPTURE LOGIC
====================================================

At the moment an F&O paper trade exits:

1. Keep existing exit decision unchanged.
2. Keep existing realized exit premium unchanged.
3. Attempt to fetch nearest trusted market option premium for the exact contract.
4. Use only trade-grade trusted source.
5. Check freshness/as-of.
6. If available, store exit_premium_market.
7. If unavailable, store null + reason.
8. Calculate market shadow P&L separately.

Required formula:

market_shadow_gross_pnl =
  direction-adjusted quantity * (exit_premium_market - entry_premium)

For long option paper trades:

market_shadow_gross_pnl =
  (exit_premium_market - entry_premium) * quantity

Then calculate charges using canonical F&O cost model.

market_shadow_net_pnl =
  market_shadow_gross_pnl - market_shadow_total_charges

Required comparison:

exit_premium_gap =
  exit_premium_market - exit_premium_realized_or_projected

exit_premium_gap_pct =
  exit_premium_gap / exit_premium_realized_or_projected

Do not let market shadow values affect:

- exit decision,
- realized P&L,
- account balance,
- trade status,
- Telegram alerts,
- signal quality scoring.
