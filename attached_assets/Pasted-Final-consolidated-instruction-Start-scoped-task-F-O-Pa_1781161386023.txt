Objective 1 — Dynamic F&O lot sizing using available cash

Replace fixed-lot STANDARD sizing with available-cash-based dynamic sizing.

Approved formula:

riskBase = availableCash

perTradeRiskBudget = availableCash × maxLossPctPerTrade

heatCap = availableCash × MAX_FNO_HEAT_PCT

riskPerLot = abs(entryPremium - stopPremium) × lotSize

maxLotsByTradeRisk = floor(perTradeRiskBudget / riskPerLot)

maxLotsByPortfolioHeat = floor((heatCap - currentHeat) / riskPerLot)

absoluteMaxLots = PAPER_FIXED_LOTS[index]

finalLots = min(
maxLotsByTradeRisk,
maxLotsByPortfolioHeat,
absoluteMaxLots
)

Rules:

PAPER_FIXED_LOTS is only the maximum ceiling.
Never force fixed lot quantity.
If fixed lots breach risk/heat, reduce lots automatically.
If finalLots >= 1, open with finalLots.
If finalLots < 1 because even 1 lot exceeds per-trade risk, block with:
RISK_TOO_WIDE_FOR_MIN_LOT
If finalLots < 1 because portfolio heat has no room, block with:
PORTFOLIO_HEAT_CAP
Keep the final heat assertion as fail-closed protection.
Do not loosen the heat gate.
Do not increase max risk percentages.
Do not allow untrusted/stale/Yahoo/synthetic premium.
Do not allow INFO_ONLY / BASELINE / OUTLOOK to open.
Do not bypass recovery-veto, chase-veto, anti-flip, liquidity, or premium-trust gates.

Correct example:
If fixed lots = 10 but only 6 lots are safe, open 6.
If only 1 lot is safe, open 1.
If even 1 lot is unsafe, block.
