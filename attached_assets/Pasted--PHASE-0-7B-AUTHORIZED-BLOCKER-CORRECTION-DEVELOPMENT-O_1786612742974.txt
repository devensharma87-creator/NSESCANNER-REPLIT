Continue Phase 0.7B only. Do not checkpoint the incomplete portion yet.

### Authorized objective

Implement the minimum supported boot mode required to start the real API server, restore Schema-5 from the development database and expose owner-only restoration diagnostics while guaranteeing:

* zero external provider calls;
* zero WebSocket creation;
* zero subscribe/unsubscribe operations;
* zero market-data schedulers;
* zero ingestor activity;
* zero registry writes;
* zero database mutation.

This mode exists only for deterministic development verification. It must not change normal development or production boot behaviour.

---

## A. MODE CONTRACT

Use one explicit environment variable:

```text
DATA_FOUNDATION_BOOT_PROOF=1
```

Requirements:

1. It must be evaluated before any provider bootstrap or scheduler side effect.
2. It must be rejected when `NODE_ENV=production`.
3. If enabled in production, startup must terminate before listening or contacting any provider.
4. Default/unset behaviour must remain unchanged.
5. It must not weaken authentication.
6. It must not bypass registry integrity or current-authority validation.
7. It must not inject fixtures or fabricated provider state.
8. It must not change safety locks.
9. It must not be a generic “disable everything” mode; explicitly enumerate what is suppressed and retained.

Retained in proof mode:

* normal application construction;
* development database connection;
* read-only Schema-5 restoration;
* integrity verification;
* current-time authority evaluation;
* coverage bridge;
* market-data health;
* authentication;
* owner-only registry-health endpoint;
* HTTP listener.

Suppressed in proof mode:

* Kite bootstrap and authentication refresh;
* Kite WebSockets;
* quote subscriptions;
* readiness/scan/provider schedulers;
* candle and option ingestors;
* global data pump;
* Yahoo;
* Binance;
* Upstox;
* IndianAPI;
* NSE/BSE downloads;
* Telegram/WhatsApp outbound delivery;
* any other external network bootstrap discovered in the startup inventory.

Do not claim isolation until every module-import and post-listen side effect is inventoried.
