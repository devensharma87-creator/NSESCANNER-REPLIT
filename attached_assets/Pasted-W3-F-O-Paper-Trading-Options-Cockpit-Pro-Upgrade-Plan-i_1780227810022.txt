# Required helper features

## 1. P25 official eligibility helper

Implement a display-only predicate matching the accepted official P25 rule:

```text id="avwiby"
status = CLOSED
exit_premium IS NOT NULL
entry_premium > 0
qty > 0
NOT (max_runup = 0 AND max_drawdown = 0)
```

Frontend field mapping:

```text id="u4ksgd"
status === CLOSED
exitPremium != null
entryPremium > 0
quantity = lots * lotSize > 0
NOT (maxRunup === 0 AND maxDrawdown === 0)
```

Important:

* Do not use raw `IS NOT NULL` MFE/MAE logic.
* Do not count 0/0 placeholder rows.
* Do not change P25 tracker logic.
* Do not change threshold.
* This helper is for UI classification only.

Suggested function names:

```text id="fx7eqn"
isP25EligibleTrade(row)
getP25EligibilityReason(row)
deriveP25Summary(rows, threshold = 20)
```

Reasons should include:

```text id="upii8z"
eligible
not_closed
missing_exit_premium
invalid_entry_premium
invalid_quantity
excluded_zero_zero_mfe_mae
missing_mfe_mae
```
