PART B — DEFINE ALERT ELIGIBILITY

Implement a strict eligibility function, preferably pure/testable:

shouldSendFnoTradeAlert(signal): boolean

It must return true only when all are true:

1. Signal is high-conviction / tradeable.
2. Signal has passed every F&O gate.
3. Signal is not baseline/outlook.
4. Signal is not info-only.
5. Signal is not suppressed.
6. Signal is not blocked by recovery veto, chase veto, data veto, stale-data veto, or risk guard.
7. Signal has fresh Kite/trusted data.
8. Option-chain data is fresh/trusted enough.
9. Entry, SL, target, R:R, quantity/risk fields are present and valid.
10. Signal is not duplicate of a recently alerted signal.

If any condition fails, do not send a trade alert.

====================================================
PART C — ALERT MESSAGE FORMAT

Telegram message must be professional, short, and non-misleading.

Example format:

⚡ F&O TRADEABLE SIGNAL

Fields:

* Index: NIFTY / BANKNIFTY / SENSEX
* Direction: CALL / PUT
* Instrument: option symbol/strike/expiry
* Signal type: TRADEABLE_SIGNAL
* Confidence score
* Entry zone
* Stop loss
* Target 1
* Target 2
* R:R
* Max risk
* Validity / expiry time
* Data source: Kite / trusted option-chain source
* Data as-of time
* Guard status: all gates passed
* Broker execution: DISABLED
* Action: Review manually before trading

Required wording:

Broker execution DISABLED — no order placed.

Required warning:

Manual review required. This is not auto-executed.

Do not write:

* guaranteed profit
* sure shot
* buy now
* auto order placed
* risk-free
* blindly enter
